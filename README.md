# IExpress Universal Shortcut

A ready-made shortcut to **IExpress**, the self-extracting package builder that ships with every copy of Windows but has no Start menu entry.

## What is IExpress

IExpress is a built-in Windows tool that wraps scripts and files into a single self-extracting `.exe`. It is a quick way to turn a batch script into something you can hand to someone as one file, with no extra software to install.

Windows hides it. To open it you normally have to type `iexpress` into the Run dialog.

## Usage

1. Download `iexpress.lnk`.
2. Put it wherever you want quick access, such as your desktop or a tools folder.
3. Double-click it to open the IExpress Wizard.

The shortcut targets `%windir%\System32\iexpress.exe`, so it works on any Windows installation regardless of the drive letter or user account.

## Requirements

- Windows 10 or Windows 11
